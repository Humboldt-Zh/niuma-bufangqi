# ADR 0004 展开时联动浮起入口

日期：2026-11-10。状态：用户已确认预览方案，0.1.6 本地实现；具体实测范围见验证记录。

## 背景与范围

用户确认只让牛马收益/倒计时入口与展开面板一起浮起。采用“展开时浮起，收起恢复嵌入”，不采用入口始终浮起模式。

本决策补充 ADR 0002：常态仍使用 Explorer 任务栏子窗口和安全槽位，展开期允许一个与面板关联的顶层入口。它不是无法挂接时的桌面浮窗兜底；没有可靠原生槽位时不显示浮起入口。

## 决策

- 保留原 WinForms child 及 UIA 布局缓存。child 的视觉显隐与已分配槽位分开，隐藏它不会清空锚点。
- 新增不透明 WPF `EntryPopupWindow`，owner 为已经显示的面板。两者属于 Topmost 组；popup 不激活、不增加普通任务栏按钮，不成为 Explorer 子窗口。
- 新 popup 准备成功后再抑制 child；收起时先恢复 child 再隐藏 popup。统一由 `EntryElevationCoordinator` 协调，合并同步重入，并对失败执行回滚。
- popup 主体内缩在原安全槽位中，使用同一计薪展示模型、面板配色、系统边框/圆角/阴影。原 child 继续使用系统任务栏配色。
- 500ms 刷新继续校验真实任务栏，但遵循当前抑制状态，不重新显示第二个入口。UIA 暂时未知沿用已确认位置，真实原生失效与可靠无空间结果仍撤掉入口。
- 失焦保护识别浮起入口，右键菜单单独追踪打开/关闭状态；关闭意图独立于尚未来得及隐藏的原生面板可见性，防止同步重入误重开。
- 退出时显式还原/隐藏入口并释放 popup。窗口关闭后解除原生 hook。

## 代价与验收

同时保留两个原生 surface，但正常时仅一个可见。需要同步 DPI、原生边界、owner 生命周期与输入顺序，不能只验证一个布尔状态。

自动测试覆盖顺序、失败、异常、重入、真实缓存序列及负坐标/DPI 几何。原生实测另检查样式、owner、可见性、单入口、点击、右键与失焦；未实测的系统菜单、自动隐藏、多屏组合保持未验证。
