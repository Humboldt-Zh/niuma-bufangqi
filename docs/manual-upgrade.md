# 手动升级与任务栏验收

适用版本：0.1.9 Windows 11 x64 开发预览版。

从 [v0.1.9 发布页](https://github.com/Humboldt-Zh/niuma-bufangqi/releases/tag/v0.1.9) 获取本版。升级后检查：面板展开后只有一个带浅绿色磨砂的浮起入口、原嵌入入口不可重复显示；点击任务栏其他应用后，入口不能持续被任务栏盖住，并检查是否仍有可见闪动；第二次点击、Esc、外部点击能收起并恢复原入口；右键菜单关闭不会误重开；无安全槽位时只使用既有托盘恢复路径。关闭系统透明效果、高对比度或节能状态下应为可读实底，恢复后重新打开可恢复材质。不要把“入口始终浮起”当作本版行为。

本版收起时将入口嵌入任务栏，展开时切换为同一槽位内的磨砂浮起入口，再次点击收起。升级步骤适用于自行下载的公开包；软件不会自动退出旧版本或接管启动项。

## 升级步骤

1. 如果旧版设置里有尚未保存的修改，先自行确认是否保存。然后在当前任务栏入口、0.1.0 浅绿色挂件或系统托盘的右键菜单选择“退出”，确保已结束包括 0.1.1 在内的旧版本。面板右上角的 `×` 只收起面板，不能彻底退出。
2. 在旧薪资时钟的任务栏入口或托盘菜单中选择“退出”。启动新包前，旧薪资时钟和旧浮窗版都应结束，避免同时出现两个入口。
3. 获取明确标记为 **0.1.9** 的 win-x64 ZIP，或从对应源码运行 `scripts/publish.ps1`。核对随包提供的 SHA-256，将 ZIP 完整解压到一个固定目录。
4. 从 Windows 文件资源管理器或桌面快捷方式运行新目录中的 `NiumaBufangqi.exe`，让日常运行独立于开发工具的会话；不要把开发宿主中临时启动的实例当作常驻入口。若提示旧薪资时钟仍在运行，或同一配置被其他目录中的旧版本占用，按提示先退出旧程序，再重新运行新包；0.1.9 不会替你结束进程，也不会再打开另一目录的旧界面。已配置用户启动后只出现任务栏入口，点击展开，在设置页底部确认版本是 0.1.9；需要启动时直接打开面板可使用 `--open`。
5. 已有原生设置继续从 `%LOCALAPPDATA%\NiumaBufangqi\state.json` 读取。已经迁移过薪资与排班的用户无需重填；如果意外变成未配置状态，先暂停保存并反馈现象，保留原配置和备份。
6. 需要桌面入口时，为这次解压目录中的 EXE 创建快捷方式，并按目标文件路径辨认或整理旧快捷方式。是否开机启动由用户决定：先在 Windows 的启动应用设置中关闭旧程序或旧路径的启动项，再按需开启新版的“随 Windows 启动”。新版开关反映当前 EXE 的实际启动项，换到新目录后未勾选是正常情况，不需要为了与旧偏好一致而重复填写薪资。

更新完成后，任务栏中应只有一个收益入口；没有工作区底部的绿色卡片，打开面板时也不应增加第二个普通任务栏按钮。

若入口没有出现，先在系统托盘查找“牛马不放器”，通过托盘打开面板。任务栏空间不足或无法安全定位时，软件会仅保留托盘；不要用重复启动多个版本来尝试恢复。

## 用户手动验收

这些是待执行项目，不代表已经通过。反馈时提供 Windows 版本、缩放比例和现象；截图请先隐藏金额，不发送个人配置文件。

- **单一入口**：只运行 0.1.9；展开/收起时始终只有一个牛马入口，磨砂浮起入口与原嵌入入口不同时停留，面板没有额外的普通任务栏按钮。
- **启动保护**：如存在旧薪资时钟或同配置的另一目录实例，0.1.9 应提示冲突并停止，不新建入口，也不激活旧版本。退出冲突程序后重新启动才继续。
- **连续点击**：第一次点击任务栏入口打开四页签面板，第二次点击同一入口关闭，第三次可再次打开。
- **失焦**：保存过薪资配置后，点击面板外部应收起面板；点击任务栏入口不能出现“刚收起又自动打开”的闪动。首次未配置状态单独记录。
- **键盘**：普通页面按 `Esc` 收起面板；有对话框时先关闭对话框。再次点击入口可恢复。
- **托盘**：任务栏入口隐藏或不可见时，托盘可恢复面板；菜单“退出”能真正结束程序。
- **启动偏好**：若用户选择自启动，确认开关与当前 EXE 的实际目标一致；旧路径的启动项应由用户单独关闭。
- **任务栏空间**：应用按钮或天气区域占满空位时，入口不覆盖系统按钮；无法安全安置时只保留托盘，不出现浮窗。
- **开始菜单**：按 Windows 键打开开始菜单，等待至少 5 秒，再收起，重复几次。入口不应短暂消失；若仍会自行恢复，请记录触发时刻，并提供本地 `logs/app.log` 中对应的 `taskbar-` 状态行，不发送个人配置。
- **自动隐藏**：启用任务栏自动隐藏的测试环境中，入口随任务栏出现和隐藏，不遗留在桌面上。
- **外框效果**：在白色页面、深色页面和壁纸背景前检查细描边、圆角和窗外投影；核对四角无白角、右上按钮可点击、边缘不产生拖动或缩放。系统投影由 Windows 管理，HTML 预览不能替代实机验收。
- **DPI 与显示器**：分别记录实际验证的缩放比例和显示器组合，检查文字、点击区域和面板边界。未测试的组合保持未验证。
- **Explorer 恢复**：在专门测试环境中观察 Explorer 重建后的重新挂接，确认没有重复入口且托盘仍可用；不需要在日常工作桌面强制重启 Explorer。
- **独立运行**：从文件资源管理器或桌面快捷方式启动后，在方便时退出并重新打开开发工具，确认主程序与入口仍在；尚未实际执行的重启或更新场景保持未验证。

## 发现问题时

先区分运行版本和入口：绿色浮动卡片属于 0.1.0，旧的简易薪资面板属于旧薪资时钟，0.1.9 应为任务栏入口加新版四页签面板。若同时出现两种界面，先通过各自菜单退出，再只启动所选版本。

若入口消失且不再恢复，先在任务管理器检查 `NiumaBufangqi.exe` 是否仍在。进程已停止时，任务栏恢复逻辑也已停止，应检查退出、崩溃或启动宿主变化，再从 Windows 文件资源管理器重新启动。2026-11-10 的一次报告确认进程已停止，时间与 Codex 更新重启重合；由于没有旧进程退出码，开发宿主生命周期影响仍是高概率推断，不能视为已证实的退出原因。详见 [验证记录](verification.md)。

不要上传 `state.json`、备份、WebView2 用户目录或写在烦恼纸上的内容。普通问题可在 [GitHub Issues](https://github.com/Humboldt-Zh/niuma-bufangqi/issues) 描述复现步骤；安全问题按 [安全说明](../SECURITY.md) 处理。
