# 验证记录

更新日期：2026-11-10。当前版本：0.1.4 任务栏模式开发预览版；保留此前版本的历史验证记录。

## 0.1.4 Edge 切窗闪隐根因修正

- 从实际日志确认 0.1.3 仍走入 `shown-cached-layout → hidden-layout-unavailable → shown-measured`，4 秒观察租约仍是应用主动隐藏入口的路径。前两次补丁未完成该场景闭环。
- 已移除“UIA 未知/旧读数超过时限就清掉已显示入口”的语义。当前原生 HWND、边界、DPI、可见性和用户开关决定已分配入口是否仍有效；新的可信观测负责更新位置。
- 等待新观测时冻结实际分配矩形和模式，防止文字增长借旧空隙扩张；新测量明确无空间立即让位，原生失效或禁用立即清理，无历史数据不猜位置。
- Monitor 增加固定原因码、实际捕获耗时与序号，缓存 frame 并排除自身进程子树。每 10 秒记录自身原生可见性健康状态，不记录薪资、控件文本、窗口标题或烦恼内容。
- 本地完整构建 0 警告、0 错误；34 项 Core、30 项任务栏数据/几何、19 项 JavaScript 测试通过，共 83 项。包括真实故障时间线、600 秒 Unknown、旧测量重放、文字增长不扩张、序号乱序及回拨等回归。
- 运行阶段需要用户反复切换 Edge 与开始菜单，并核对同一时间段的诊断和健康状态。此项在取得运行结果前保持待验收，不能以 83 项纯测试代替。

## 0.1.3 长时间遮挡几何确认

- 用户授权退出旧版并打开新版后，已确认切换为唯一的 0.1.2 实例、使用同一数据目录，设置文件哈希与启动项保持不变。
- 读取本应用安全诊断日志发现：开始菜单相关的未知布局可能持续超过 4 秒，0.1.2 仍会进入隐藏，再自动恢复。不能把第一次切换成功当作闪隐已解决。
- 增加 `LayoutOccluded`：离屏标志不再单独否定完整按钮几何，但只有与已可靠测量的完整槽位一致的新鲜几何才能续期；没有基线或槽位变化仍拒绝。
- 新增长 15 秒逐次几何确认、无基线拒绝、槽位变化拒绝、失效后不可复活、过期后新证据恢复和无效时间等回归，额外拒绝覆盖整个开始菜单的错误矩形。
- 实际编译 0 警告、0 错误；34 项 Core、23 项任务栏数据/几何、19 项 JavaScript 测试通过，共 76 项。没有通过远程桌面点击 Windows 开始按钮进行验收，最终场景仍需用户确认。

## 0.1.2 开始菜单期间的短暂闪隐

- 用户反馈点击 Windows 开始按钮后，任务栏收益入口短暂消失，随后可自行恢复。未进行远程桌面操作来复现；代码排查确认此前 UIA 失败会清空 `latest` 并立即触发隐藏。
- 现在区分原生任务栏不可用、布局暂时未知、完整布局测量三个状态。暂时未知时仅在同一 HWND、边界和 DPI 下复用最近可靠测量，最长 4 秒；失败读数不会续期。
- 已确认空间不足的新测量覆盖旧布局，不能在后续未知状态下恢复旧安全位置。任务栏隐藏、父句柄/几何/DPI 改变、禁用入口、未来或过期读数立即失效。
- 沿用布局时仍执行分层重绘、子窗口层级恢复和无激活显示，不再走临时未知即隐藏的提前返回。
- 构建为 0 警告、0 错误；34 项 Core、17 项任务栏数据/几何、19 项 JavaScript 测试通过，共 70 项。新增 9 个恢复序列用例均为纯数据测试，不查询实际 Explorer。
- 本地诊断日志仅记录入口状态切换原因，不记录薪资、窗口标题或烦恼内容。真实开始菜单场景仍由用户按手动验收确认。

## 0.1.1 任务栏入口改造

- 已删除 `WidgetWindow` 和原工作区浮动卡片布局，入口由 WinForms 分层子窗口挂接到主任务栏；WPF 面板 `ShowInTaskbar=false`，不增加普通任务栏按钮。
- 同一入口的点击按真实 `Window.IsVisible` 切换；非激活入口与失焦命中保护配合，避免第二次点击先收起又打开。托盘左击为明确打开，不再追加一次切换。
- 面板按任务栏入口矩形定位，不再预留原绿色卡片的 51 DIP 空间。未配置用户仍可进入设置；已有配置启动时只显示任务栏入口。
- `scripts/build.ps1` 实际运行成功：0 警告、0 错误；34 项 Core 测试、8 项任务栏安全几何测试与 19 项 JavaScript 测试通过，共 61 项。
- 新增回归覆盖点击和失焦的两种事件顺序、托盘打开幂等、极小工作区/高 DPI/负坐标显示器、入口安全空隙及紧凑/托盘回退，以及旧版隐藏绿卡偏好不影响新入口。
- 新增任务栏入口显隐字段 `TaskbarEntryVisible`，保留旧 `WidgetVisible` 供兼容但不创建其界面；旧配置无需填写真实薪资到项目中。
- 为避免用户再打开旧版本，面板标题栏与设置页展示当前版本，打包资源 URL 带版本并由构建检查一致性。
- 已增加启动冲突提示：旧薪资时钟或另一目录的旧原生版本仍运行时，不创建新入口、不自动结束其他进程。快捷方式和启动项由用户自行确认。
- **本轮仅修改源码、运行纯逻辑测试、编译和打包；未启动实际软件、未操控任务栏/Explorer、未修改用户运行进程、配置、快捷方式或启动项。**
- **任务栏的实机挂接、连续点击开关、真实自动隐藏/Explorer 重建、多屏和各 DPI 组合仍待用户按 [手动验收](manual-upgrade.md) 执行。纯测试通过不能代替这些实测。**
