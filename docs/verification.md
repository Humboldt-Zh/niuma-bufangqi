## 0.1.9 提前恢复以减少闪动

- 在 0.1.8 已改善持续消失的基础上，响应用户仍看到一次闪动的反馈，新增 `EntryLayerMonitor`：外部 foreground 和目标任务栏进程的 reorder 事件只负责排队通知，Dispatcher 合并后重新检查实际覆盖，再走原有协调器恢复。
- foreground 可能早于 Shell 完成抬升，事件后用有限 20ms 间隔补查，总计约 100ms，随后停止；隐藏或关闭时停止 timer，关闭解除 hook，Explorer 任务栏身份变化重绑，hook 创建失败可在之后重试。原 500ms 刷新保留为兜底。
- 跨进程原生 `LayerMonitorSmoke` 验证目标窗口/子窗口事件递送、其他同进程窗口过滤、SKIPOWNPROCESS、重绑、清空及 Dispose 后不触发，全部通过。自有 actor 使用受控 NotifyWinEvent；这证明递送与过滤，不代表 Shell 每次顶层 Z 序变化必发 reorder。
- 更新后的真实生产窗口原生 smoke 再跑 10 轮遮挡恢复，焦点、owner、边界、合法浮层保护与 native/WPF 可见性恢复全部通过；临时测试窗已关闭。一次运行期间有外部焦点变化导致断言失败，保留原失败文件后重跑通过，未把失败运行计作成功。
- 本地完整构建 0 警告、0 错误，34 Core + 60 Taskbar + 19 JavaScript，共 **113 项**通过；当次使用锁定的本地依赖缓存，在线依赖审计未执行。本地验收 ZIP 的 SHA256：`2f5f0c2985acbcdfc4f4a6edc72803b4aceb6c453f2a400149e6b837baa16f4e`。
