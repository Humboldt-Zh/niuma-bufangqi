# 摸鱼文化报告的话术改写记录

## 采用的方向和落点

报告 2.2 节谈到不把自我价值绑定在 KPI 上。本轮把这个方向写入“有点烦”和“想摆烂”的回应，例如“需求又更新了，你不用顺便把内耗也更新”“发呆五分钟，不用顺便考个证”。它们由本项目重新组织表达，落点是让人暂时卸下负担。

报告 2.1 节的充电意象、4.3 节的自我照顾场景，适合现有的休息计时。休息页新增“这几分钟，先不生成任何待办”和“手机充电，你也充电”，把梗落到接水、松肩、看远处等简单选择；“看看远处”的反馈改为“看会儿窗外，云今天也没交周报”。没有设置喝水量、如厕次数、保健效果或养生成就任务。

报告 4.3 节中的周末期待，以及 5.2 节的自嘲和同伴感，适合情绪回应与角色彩蛋。“还不错”的回应包括“今天攒到一点开心，晚上记得花掉”；角色气泡新增“摸鱼搭子已就位”。这些是虚构陪伴角色的文案，没有暗示真实用户都在这样做。

揉纸的预设话题改为具体的工位烦恼，包括会议拖长、临下班收到消息等场景。落篓后的反馈增加“这张纸，不用交周报”“纸篓也不催进度”等原创表述，并继续提供再来一张、休息和返回选项。

## 没有转成产品规则的内容

报告中的装忙教程、故意拖延或办坏工作、关闭自动锁屏、监测旁人位置等内容没有加入。它们与当前“短暂安慰、照顾自己”的用途不一致。

报告中的饮水、如厕、促排便等操作没有作为健康建议采用；MBTI 划分及“复利型摸鱼”没有转为用户标签、学习任务或副业清单，避免给休息增加另一份考核。
